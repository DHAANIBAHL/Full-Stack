# Web Development Learning Repository

This repository documents my learning journey in **web development**, covering HTML, CSS, JavaScript, Node.js, and React.

It contains programs, practice exercises, experiments, and projects that I build while learning and applying different concepts. The repository will be updated continuously as I explore new topics and improve my skills.

## Technologies Covered

* **HTML** – Structure and semantics of web pages
* **CSS** – Styling, layouts, responsiveness, animations, and UI effects
* **JavaScript** – Programming fundamentals, DOM manipulation, events, functions, and interactivity
* **Node.js** – Server-side JavaScript, modules, built-in APIs, and backend concepts
* **React** – Components, props, state, events, rendering, and React ecosystem
